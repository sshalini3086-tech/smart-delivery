📚 Algorithm Information

🫧 Bubble Sort

Repeatedly compares adjacent orders and swaps them.


Time: O(n²)

🎯 Selection Sort

Finds the minimum element and places it at the correct position.


Time: O(n²)

🃏 Insertion Sort

Builds a sorted list by inserting each order into its correct position.


Time: O(n²)

⚡ Quick Sort

Uses a pivot to divide the order list into smaller sections.


Average: O(n log n)

🔎 Linear Search

Checks every order one by one until the required order is found.


Time: O(n)

🔍 Binary Search

Searches a sorted list by repeatedly dividing the search area.


Time: O(log n)

🌐 BFS

Visits nearby delivery locations level by level.


Time: O(V + E)

🌳 DFS

Explores one route deeply before moving to another route.


Time: O(V + E)

📋 Queue

Uses FIFO: First In, First Out.


Application: Delivery orders
